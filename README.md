## ✨ Features

- **Dynamic Hero Section** – Typewriter effect, floating medical particles, and a heartbeat pulse ring on the profile image.
- **10+ Mastered Tools** – EMR/EHR Systems, Google Workspace, Telehealth Platforms, Calendly, Microsoft 365, and more.
- **Healthcare Services** – 9 comprehensive services for healthcare professionals.
- **Experience Timeline** – 3 professional roles with detailed descriptions, skills, and impact stats.
- **Case Study Modals** – Interactive cards that open detailed project breakdowns:
  - Patient Care Plan System
  - Telehealth Implementation
  - Appointment Scheduling System
- **Auto-Smooth Carousels** – Seamless, continuous sliding carousels for:
  - **Work Samples** (10 unique project images)
  - **Testimonials** (10 client reviews)
- **Visual Enhancements**:
  - ECG / Heartbeat canvas animation at the bottom of the page.
  - Floating medical icons (stethoscope, heartbeat, pills, syringe, hospital, etc.)
  - Geometric medical cross shapes in the background.
  - 3D tilt effect on cards.
  - Custom cursor & glow trail (desktop).
- **Social Media Preview (Open Graph / Twitter Cards)** – Shares a rich preview with profile photo, title, and description on LinkedIn, X, Facebook, and WhatsApp.
- **Fully Responsive** – Optimised for desktop, tablet, and mobile devices.
- **Booking Section** – Quick action buttons for Calendly scheduling, email, WhatsApp, and resume download.
- **Contact Form** – Integrated with Formspree (`https://formspree.io/f/mnjeryvy`) for easy messaging.

## 🚀 Getting Started (Local Development)

Follow these steps to run the project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/IamSalvation/Ochonma-C_portfolio.git
   cd Ochonma-C_portfolio
Add your images
Place your profile photo and work sample images into the assets/ folder.
(Make sure the filenames match those referenced in index.html).

Open the site
You can simply open index.html in your browser. For the best experience (to avoid CORS issues with fonts or icons), use a local development server:

Using VS Code – install the Live Server extension and click "Go Live".

Using Python – python -m http.server 8000 and visit http://localhost:8000.

🌐 Deployment (GitHub Pages)
This repository is configured for GitHub Pages. To deploy your live site:

Push your code to the main branch.

Go to your repository on GitHub → Settings → Pages.

Under Branch, select main and save.

After a few minutes, your site will be live at:
https://IamSalvation.github.io/Ochonma-C_portfolio/

📝 Customisation Tips
Change the profile image – Replace assets/Ochonma.jpg with your own photo.

Update social links – The contact section includes GitHub, LinkedIn, Facebook, Email, Phone, and Calendly. Update the href attributes in index.html if needed.

Modify the typewriter phrases – Edit the phrases array in script.js (currently: Medical Virtual Assistant, Telehealth Nurse, Care Coordinator, Healthcare Administrator, Patient Advocate).

Adjust the carousel speed – Look for 3500 (work samples) and 4000 (testimonials) in script.js to change the slide interval.

Update the Formspree endpoint – The form currently submits to https://formspree.io/f/mnjeryvy. Replace it with your own Formspree ID if needed.

Update Calendly link – The booking button links to https://calendly.com/confidenceochonma2. Update with your own Calendly URL.
